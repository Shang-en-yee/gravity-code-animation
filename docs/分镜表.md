## 逐段

### 0 · 开篇（6s）
- 画面：220 颗星，三层景深，极缓横移
- 文字：「引力」150px + `GRAVITY`
- 动效：粒子迸发（120 颗，0.9 秒散开），标题上浮 + 由虚到实

### 1 · 苹果与月亮（16s）
- 画面：椭圆轨道按时间画出（1.7s 画完），行星沿轨道走一圈
- 公式：`F = G · mM / r²`，右上，2.2s 时淡入
- 字幕三段：
  1. 1687 年，牛顿用一个公式，把苹果和月亮绑在了一起。
  2. 引力与质量成正比，与距离的平方成反比。
  3. 但他没有解释：这个"超距作用"，究竟是什么。

### 2 · 两个异常（15s）
- 画面：进动椭圆，两圈半，每圈偏 0.19 弧度，形成花瓣
- 字幕三段：水星 43 角秒 / 1919 日食 / 牛顿理论失手

### 3 · 电梯（15s）
- 画面：3:4 方框，内部横线随 1.1Hz 轻微升降，中心白点自由浮动
- 字幕三段：自由下落 / 感觉不到引力 / 加速与引力不可区分

### 4 · 弯曲（20s）
- 画面：**核心镜头**。38×38 透视网格，中心被压出漏斗；相机 yaw 随时间缓慢增加（0.045 rad/s），形成横移
- 细节：网格边缘用径向渐隐，避免出现"悬浮方板"
- 字幕三段：质量→弯曲 / 时空→运动 / 行星走的是最直的路

### 5 · 证据（20s）
- 画面：左侧三层同心透镜环 + 被拉成弧的背景星系；右下啁啾波形（频率上扬）
- 字幕三段：引力透镜 / GPS 每天 38 微秒 / 2015 听见引力波

### 6 · 视界（14s）
- 画面：吸积盘三条椭圆环（在阴影后）、纯黑圆面、亮光子环
- 字幕三段：光也出不去 / 2019 拍下影子 / 时间与空间交换角色

### 7 · 落版（11s）
- 文字：两行 64px
  > 时空告诉物质如何运动，
  > 物质告诉时空如何弯曲。
- 小标：`SPACETIME TELLS MATTER HOW TO MOVE`
- 最后 1.2 秒整体淡出

## 技术要点（和论文的对应）

| 论文里的特征 | 在本片里怎么体现 |
|---|---|
| F1 近黑底 | `#05060A`，不是纯黑 |
| F2 单主色 | 橙 `#E0813C` 唯一强调色，冷蓝只在波形里出现一次 |
| F3 发光而非投影 | 全局廉价 bloom：画布缩到 1/6 再放大叠加，替代 `shadowBlur` |
| F4 固定机位 | 唯一的"运镜"是网格 yaw 0.045 rad/s，其余全靠元素变化 |
| F5 低密度 | 一屏最多一个主体 + 一行字幕 |
| F6 固定节拍 | 每段 14–20 秒，切换靠粒子迸发 |

**"新审美"的三处尝试：**

1. **粒子迸发做转场**——不用淡入淡出，用 120 颗粒子从中心炸开，0.9 秒内消失
2. **伪 3D 透视**——手写投影矩阵（yaw/pitch/dist），没有用 three.js，网格是纯 Canvas 2D 画的
3. **廉价 bloom**——一次 downscale + 一次加性叠回，两行代码换掉所有 `shadowBlur`
